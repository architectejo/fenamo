{% translate "Le principe" %}

{% translate "Le site ne crée pas de compte et ne garde aucune donnée personnelle. Il ne contient ni publicité ni mesure d'audience. Les informations que vous saisissez dans un formulaire sont transmises à l'application de gestion de la FENAMO-RDC, qui est seule à les traiter et à les conserver." %}

{% translate "Les formulaires" %}

{% translate "Lorsqu'ils sont ouverts, les formulaires du site collectent seulement ce qui est nécessaire à leur objet :" %}

  • {% translate "Contact" %} {% translate ": votre nom, un téléphone ou une adresse e-mail, l'objet et le message, pour vous répondre." %}
  • {% translate "Demande d'adhésion" %} {% translate ": les informations de l'association et de son responsable, et les pièces jointes (statuts, agrément), pour examiner la demande. Les pièces sont transmises à l'application de gestion puis effacées du serveur du site." %}
  • {% translate "Suivi d'une demande" %} {% translate ": la référence de la demande et l'adresse e-mail du demandeur, pour afficher l'état de la demande." %}

{% translate "Ce que montre la vérification" %}

{% translate "La vérification d'une carte de membre affiche seulement : la photo, le nom, l'identifiant MBR, la qualité, l'association membre, la coordination, l'antenne, le parking, l'état et la validité de la carte. Pour un engin : le numéro FENAMO, le type, la marque, la couleur, la plaque, le nom du propriétaire, le motocycliste rattaché, l'état et la validité de l'identification." %}

{% translate "Elle n'affiche jamais l'adresse, le téléphone, l'adresse e-mail, la date et le lieu de naissance, la filiation, l'état civil, le numéro de carte d'électeur ou de permis, les pièces jointes, la famille, l'historique ni les paiements. Chaque vérification est comptée (date et résultat), sans enregistrer l'identité de la personne qui la fait." %}

{% translate "Chiffres publiés" %}

{% translate "Les chiffres affichés sur le site (membres actifs, associations membres, coordinations) sont des totaux : ils ne permettent d'identifier personne." %}

{% translate "Cookies et stockage dans votre navigateur" %}

{% translate "Le site n'utilise aucun cookie publicitaire ni de suivi. Il garde dans votre navigateur le thème clair ou sombre que vous choisissez. Les formulaires utilisent un cookie technique de sécurité, le temps de la saisie. La carte Google Maps de la page Contact ne se charge que si vous la demandez." %}

{% translate "Durée de conservation" %}

{% translate "La durée de conservation des messages et des demandes d'adhésion est fixée par la FENAMO-RDC. Elle sera indiquée ici avant l'ouverture des formulaires." %}
