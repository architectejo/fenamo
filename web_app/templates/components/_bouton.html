{% comment %} Bouton (ou lien d'action). Un bouton dit ce qu'il fait : « Valider le membre », jamais « Soumettre ». Paramètres : libelle texte (obligatoire, traduit par l'appelant : with libelle=_("Valider le membre")) variante "" (secondaire, défaut) | "principal" | "valider" | "danger" | "danger-plein" | "discret" icone nom d'icône à gauche (facultatif) taille "" | "petit" bloc True : pleine largeur href si présent, rend un type "button" (défaut) | "submit" hx_get, hx_post, hx_target, hx_swap attributs HTMX (facultatifs) modale True : la réponse de hx_get va dans la modale commune (#modale-contenu) etiquette aria-label si le libellé seul est ambigu (facultatif) Pendant la requête : hx-disabled-elt="this" désactive le bouton, .htmx-request affiche la roue à la place de l'icône. Règles : un seul « principal » par zone ; « valider » réservé au circuit de validation ; « danger-plein » seulement dans une modale de confirmation.
