{% comment %} Zone des bulles (toasts), incluse une fois dans base.html. Les bulles sont créées par FenamoDesign.bulle() : - après une requête HTMX : en-tête HX-Trigger {"toast": {"message": "Membre validé", "detail": "...", "niveau": "success"}} ; - au chargement d'une page complète : les messages Django ci-dessous sont convertis par fenamo.js (data-niveau = level_tag). Niveaux : success (vert), error / danger (rouge, reste 9 s, role="alert"), warning (jaune), info. Écriture : le message reprend le verbe du bouton (« Valider le membre » → « Membre validé ») ; le détail dit la suite. Position : en haut sous la barre sur téléphone (loin du pouce et de la barre basse), en bas à droite dès 576 px. Les vues héritées passent locals() au gabarit (variable « messages » masquée) : le contexte fournit donc fn_messages (fenamo/contexte.py). Usage : {% include "components/_bulles.html" %} {% endcomment %}
